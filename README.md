# Log Analyzer

**Simple GUI tool to analyze API failure logs** - Point, click, get results.

## Why I Built This

I work at **Keepit** analyzing lots of API logs every day. Manually searching through thousands of lines for failures was killing me.

So I took the **initiative** and built this small Python script in a few hours. Now I can:

1. Click **Browse** → pick log file
2. Click **GENERATE REPORT** → done!

##  Quick Start

```
git clone https://github.com/VasilisKokotakis/Log-Analyzer.git
cd Log-Analyzer
python3 main.py
```

##  Requirements
- Python 3.8+
- That's it! (tkinter included)
